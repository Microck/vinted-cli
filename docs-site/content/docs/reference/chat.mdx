## `vinted chat`

Read and send Vinted messages

Read and send Vinted messages.

CONV is a numeric conversation id, as listed by "vinted chat list".

```bash
vinted chat list --unread --format pretty
vinted chat show 1234567890 --format pretty
vinted chat send 1234567890 "Is it still available?"
vinted chat start 4815162342 "Hi, would you ship today?"
vinted chat open 1234567890
vinted chat offer 1234567890 20
echo "Would you take 20?" | vinted chat send 1234567890 -
```

## `vinted chat list`

List conversations, most recent first

```bash
vinted chat list [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--limit` | int | `20` | how many conversations |
| `--unread` | bool | `false` | only conversations with unread messages |

## `vinted chat offer`

Send a price offer, or accept/decline an incoming one

```bash
vinted chat offer CONV AMOUNT [flags]
```

Send a price offer in the conversation's currency. AMOUNT is a positive
decimal with at most two fractional digits. As the buyer this is an offer
request; as the seller it is a counter offer. Sellers answer the latest
pending offer with:
  vinted chat offer accept CONV
  vinted chat offer decline CONV
Vinted checks its own minimum and daily limits and reports them as errors.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--currency` | string | - | currency code (default: the conversation's) |

### `vinted chat offer accept`

Accept the latest pending offer (seller)

```bash
vinted chat offer accept CONV
```

### `vinted chat offer decline`

Decline the latest pending offer (seller)

```bash
vinted chat offer decline CONV
```

## `vinted chat open`

Line-mode chat: polls for incoming messages, sends what you type

```bash
vinted chat open CONV [flags]
```

Line-mode chat for one conversation. Prints the recent history, then polls
for new messages every --interval (default 30s, floor 10s) while each line you
type is sent. /quit or Ctrl-D exits. Vinted's web app has no realtime channel
the CLI can use, so new messages show up within one interval. A block from
Vinted's bot protection ends the chat with exit 5.
With --format jsonl, incoming messages are printed as JSON objects instead.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--interval` | duration | `30s` | how often to poll for new messages (floor 10s) |

## `vinted chat reserve`

Reserve your item for the buyer in a conversation (or --off)

```bash
vinted chat reserve CONV [flags]
```

Mark the conversation's item as reserved for that buyer, as the seller's
"Mark as reserved" button does. Vinted ties a reservation to one buyer, so it
is set from the conversation, not the item. --off clears it.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--off` | bool | `false` | clear the reservation |

## `vinted chat send`

Send a message into an existing conversation (TEXT - reads stdin)

```bash
vinted chat send CONV TEXT
```

## `vinted chat show`

Show a conversation's messages, oldest first

```bash
vinted chat show CONV [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--limit` | int | `30` | how many of the newest messages to show (0 = all) |

## `vinted chat start`

Message an item's seller (Vinted reuses the conversation about it if one exists)

```bash
vinted chat start ITEM TEXT
```
