## `vinted search`

Search the catalog

```bash
vinted search [text...] [flags]
```

Search the Vinted catalog of the profile's site.

Common filters are flags; ids for --catalog and --brand come from
`vinted category list` and `vinted brand search`. Any other catalog query
parameter goes through --filter key=value verbatim. No login is needed.

```bash
vinted search "levis 501" --price-to 30 --order newest_first --format pretty
vinted search --catalog 1206 --brand 53 --condition very_good --condition good
vinted search nike --pages 3 --limit 100 --format jsonl
vinted search nike --page 2
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--attr` | stringArray | `[]` | any other filter as `CODE=ID[,ID]`, repeatable (codes and ids from vinted search filters) |
| `--brand` | intSlice | `[]` | brand `id`, repeatable (ids from vinted brand search) |
| `--catalog` | intSlice | `[]` | category `id`, repeatable (ids from vinted category list) |
| `--color` | intSlice | `[]` | colour `id`, repeatable (ids from vinted search filters) |
| `--condition` | stringSlice | `[]` | item condition, repeatable: new_with_tags, new_without_tags, new, very_good, good, satisfactory, not_fully_functional, or a status id |
| `--currency` | string | - | `code` of the --price-from/--price-to currency (EUR, USD...; default the site's) |
| `--filter` | stringArray | `[]` | any other catalog query parameter as `key=value`, repeatable, sent verbatim |
| `--language` | intSlice | `[]` | book language `id`, repeatable (books) |
| `--limit` | int | `0` | stop after this many items (0 = whole pages) |
| `--material` | intSlice | `[]` | material `id`, repeatable (ids from vinted search filters) |
| `--model` | intSlice | `[]` | model `id`, repeatable (phones and other electronics) |
| `--order` | string | - | order: relevance, newest_first, price_low_to_high, price_high_to_low |
| `--page` | int | `1` | first result page |
| `--pages` | int | `1` | how many result pages to fetch (max 5) |
| `--pattern` | intSlice | `[]` | pattern `id`, repeatable (clothing) |
| `--platform` | intSlice | `[]` | video game platform `id`, repeatable (video games) |
| `--price-from` | float64 | `0` | minimum price |
| `--price-to` | float64 | `0` | maximum price |
| `--sim-lock` | intSlice | `[]` | SIM lock `id`, repeatable (phones) |
| `--size` | intSlice | `[]` | size `id`, repeatable (ids from vinted search filters --catalog ID) |

## `vinted search filters`

List the catalog filters with their option ids

```bash
vinted search filters [text...] [flags]
```

List the filters Vinted offers for a search, as the site's filter bar shows
them: each filter's code, whether several options can be picked, the search
flag that sets it (--attr CODE=ID for filters without their own flag), and
every option id with its title. Options depend on the category, so pass
--catalog for the category you search in. Brand lists only popular brands;
find any other with `vinted brand search`. The other search flags narrow the
options the way a selection on the site does.

The filter list is one request to Vinted and each filter's options one more,
as on the site; --code loads only the options of the filters named.

```bash
vinted search filters --format pretty
vinted search filters --catalog 1845 --code size --format pretty
vinted search filters --catalog 1845 | jq '.[] | {code, params}'
```
