## `vinted profile`

Manage named accounts

## `vinted profile list`

List profiles with a session

```bash
vinted profile list
```

## `vinted profile remove`

Delete a profile's session, config and watches

```bash
vinted profile remove NAME [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--yes` | bool | `false` | do not prompt |

## `vinted profile use`

Make a profile the default

```bash
vinted profile use NAME
```
