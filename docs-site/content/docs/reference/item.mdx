## `vinted item`

Inspect and act on an item

Inspect and act on an item. ITEM is the numeric item id or an item URL
from any Vinted domain (https://www.vinted.fr/items/123-slug).

## `vinted item create`

Publish a new item with one or more images

```bash
vinted item create [flags]
```

Publish a new item as the active profile, or save it as a draft with
--draft (visible only to you; finish it in the web app).

--category takes a leaf category id or an unambiguous name. --condition,
--size and --attr values are checked against what Vinted offers for that
category, by name or id, before anything is uploaded. Attributes the category
requires (condition, usually size) must be given. Publishing (not --draft)
also needs --brand and --color for most categories; Vinted names any missing
field in its error (exit 2).

```bash
vinted item create --title "Levi's 501" --description "Worn twice" --price 25 --category 1840 --condition "Very good" --size "W32" --brand "Levi's" --color Blue --image front.jpg --image back.jpg
vinted item create --title "Lego 42083" --description "Complete" --price 120 --category "Lego" --condition "New with tags" --image box.jpg --draft
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--attr` | stringArray | `[]` | other category attribute code=value, value as name or id (repeatable) |
| `--brand` | string | - | brand: name or id |
| `--category` | string | - | category: leaf id or name (see `vinted category list`) |
| `--color` | stringArray | `[]` | colour name or id (repeatable, at most 2) |
| `--condition` | string | - | condition: name or id (e.g. "New with tags", "Very good") |
| `--currency` | string | - | currency code (default: the account's) |
| `--description` | string | - | item description |
| `--draft` | bool | `false` | save as a draft instead of publishing |
| `--image` | stringArray | `[]` | image file to upload (repeatable, at least one) |
| `--package-size` | string | - | shipping size: small, medium, large or id (default: smallest offered) |
| `--price` | float64 | `0` | price, in the account's currency |
| `--size` | string | - | size: name or id, for categories that have sizes |
| `--title` | string | - | item title |

## `vinted item delete`

Delete one of your items (or, with --draft, a draft)

```bash
vinted item delete ITEM [flags]
```

Delete one of your items for good. With --draft, ITEM is the id of an
unpublished draft (as printed by `vinted item create --draft`), which is
discarded instead. Asks for confirmation unless --yes is given.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--draft` | bool | `false` | ITEM is a draft id |
| `--yes` | bool | `false` | do not prompt |

## `vinted item edit`

Change title, description, price, attributes or images on your item

```bash
vinted item edit ITEM [flags]
```

Change fields on one of your items, as saving the web app's edit form
does. Only the flags given change. --condition, --size and --attr are checked
against the item's category (or the new --category).

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--attr` | stringArray | `[]` | other category attribute code=value, value as name or id (repeatable) |
| `--brand` | string | - | brand: name or id |
| `--category` | string | - | new category: leaf id or name (see `vinted category list`) |
| `--color` | stringArray | `[]` | colour name or id (repeatable, at most 2) |
| `--condition` | string | - | condition: name or id (e.g. "New with tags", "Very good") |

| `--image` | stringArray | `[]` | replacement image files (repeatable); replaces every photo |

## `vinted item images`

Image links in gallery order, or download them

```bash
vinted item images ITEM [flags]
```

Return direct image URLs for an item id or full item URL, in gallery order.
JSON returns an array of URL strings; JSONL returns one JSON string per line;
--format pretty prints one plain URL per line. `item show` lists the same
photos with the size of the uploaded original. The links are the largest
rendition the page offers (f800), which can be smaller than the original:
a 1200x1600 upload is served at 600x800.

--download DIR saves the photos into DIR as ITEMID-N.webp (N from 1, the
extension from the image type) and prints what it wrote instead. Every photo
is one request to Vinted's image host, paced and counted like any other
request; --limit caps how many are fetched.

```bash
vinted item images 4815162342 --format pretty
vinted item images 4815162342 --download ./photos --limit 3
vinted item show 4815162342 | jq -r '.images[]'
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--download` | string | - | save the photos into this `dir` |
| `--limit` | int | `0` | with --download, fetch at most this many photos (0 = all) |

## `vinted item open`

Open the item in the browser

```bash
vinted item open ITEM
```

Open the item in the browser. ITEM must be an item id or an http(s) item
URL on a Vinted domain; a URL opens as given, a bare id as
\<profile site>/items/ID, which Vinted redirects to the full item URL.
Nothing is requested from Vinted.

## `vinted item show`

Everything the item page shows

```bash
vinted item show ITEM [flags]
```

Show everything the item page shows: price with the buyer protection fee
and total, shipping, all photos (with the original upload size), description,
brand, size, condition, colour and every other detail line (material,
measurements... whichever the item has), the category path, when it was
uploaded (as the page words it: "6 hours ago"), favourites, status flags and
the seller box (login, rating, reviews, last seen). Vinted's item page shows
neither views nor an exact upload date.

--seller also loads the seller's public profile (city, country, exact last
login, items, followers): one more request.

```bash
vinted item show 4815162342 --format pretty
vinted item show https://www.vinted.com/items/4815162342-jeans --seller
vinted item show 4815162342 | jq '{price, total_price, shipping}'
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--seller` | bool | `false` | also load the seller's public profile (one more request) |
