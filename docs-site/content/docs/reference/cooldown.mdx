## `vinted cooldown`

Show or lift the pause after Vinted blocked a request

```bash
vinted cooldown
```

When Vinted's bot protection (Datadome/Cloudflare) blocks a request, the CLI
stops contacting that site for 6 hours (longer if Vinted's Retry-After asks
for it), in every process and profile on this machine: retrying while blocked
only extends the block. Commands fail at once with exit 5 and the time left,
without sending anything.

A logged-in profile's session engine is paused for as long, so it does not
renew the session while the site is blocking. "vinted cooldown" shows the
state for the profile's site. "vinted cooldown clear" lifts both early. Only do that once Vinted works normally in your browser
again (solve any captcha there, then re-export cookies with "vinted auth login"
if the session was blocked).

```bash
vinted cooldown
vinted cooldown clear --yes
```

## `vinted cooldown clear`

Lift the cooldown for the profile's site now

```bash
vinted cooldown clear [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--yes` | bool | `false` | do not ask for confirmation |
