## `vinted alert`

Vinted's saved searches (server-side alerts), read-only

## `vinted alert list`

List the account's saved searches

```bash
vinted alert list [flags]
```

List the searches the account saved on Vinted (the ones it sends new-item
alerts for), with the query each one runs. --all adds the recent searches
the search box remembers. Turn one into a local watch with:

  vinted watch add search --from-alert ID --name NAME

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--all` | bool | `false` | include recent (unsaved) searches |
